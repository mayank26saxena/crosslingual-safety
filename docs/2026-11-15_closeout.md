## Main finding

Both models show a large explicit-refusal gap between Hindi and English on the same requests. The causes differ:

- **Qwen3-8B:** Hindi harm is recognised at English strength, and the missing explicit refusals mostly become soft refusals. A push along an
  English-fitted explicit–soft direction raises Hindi explicit refusal, but it raises English too, and it did not pass confirmation on Bengali.
- **Llama-3.1-8B:** Hindi harm is recognised weakly (28% of the English projection), and the missing refusals mostly become compliance.

## Future work

Ordered by how directly each item follows from the results.

1. **Llama: a gate set on Hindi data.** The carried-over gate read the English refusal direction with an English threshold. It opened on 1%
   of Hindi harmful prompts, so Phase 6 never really tested the push in Hindi. Choosing τ on Hindi development prompts would answer whether the
   push works in Llama once it fires. This is the cheapest next step.
2. **Llama: boost harm recognition instead of wording.** Llama's shortfall is on the refusal direction itself, so the matching intervention
   adds the refusal direction (layer 10) for Hindi input, rather than the explicit–soft direction. The main risk is over-refusal on harmless
   Hindi.
3. **Qwen: neuron shift sweep (drafted as Phase 5b, not run).** This tests larger shifts (k ∈ {2, 3}) of the 100 Phase 5 neurons on
   development items, against random neurons, to see whether Hindi moves at all before damage. The draft is kept with the working notes.
4. **A fix that narrows the gap rather than raising every language.** Every Qwen push raised English as much as Hindi. A language-conditional
   gate, or a direction fitted on the Hindi–English difference, is the natural next design.
5. **Non-mechanistic baselines:** translate the request to English first, or add a system prompt in the user's language. These give
   reference points for any activation-level fix.
6. **Fine-tuning** (for example LoRA on Hindi refusals), as an upper bound on what training can do compared with steering.
7. **Breadth:** more model families and sizes, more languages (Bengali was used for confirmation only), sampled decoding as well as greedy.

**Data constraint for any of these:** the sealed split, all Bengali IndicSafe items and the Phase 6 Llama test set are used. A new
confirmation set, untouched by any run here, is needed before any tuned fix can be claimed.
