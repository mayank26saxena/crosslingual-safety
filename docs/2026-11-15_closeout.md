# Project close-out and future work

**Date:** 2026-11-15, updated the same day. **Decision:** the first version of this document closed the project after Phase 6. The
author then reopened it for one more study, Phase 7 (a Llama fix, pre-registered in `prereg/2026-11-15_v2_phase7_llama_fix.md`), so
that both models have a diagnosis and a tested fix. No study beyond Phase 7 is run here. Everything under future work is out of scope and
not pre-registered.

## Exit criteria

The project closes when all of these hold:

1. Every pre-registered study has a result document with its registered outcome, including failures. **Done** (table below).
2. Every number in the results is produced by a committed script from tracked, id-only labels. **Done** (`REPRODUCE.md`,
   `results/v2/labels/`, `MANIFEST.sha256`).
3. The Phase 6 human check (60 Hindi Llama replies, κ ≥ 0.7) is graded and the analysis rerun. **Done: below bar** (four-label κ 0.643),
   so Llama numbers are provisional (`results/2026-11-16_llama_human_checks.md`).
4. Phase 7 has its registered outcome: stage 1 selection (R3, with the corrected E arms, addendum 2) and the stage 2 test. **Done**
   (F1 not met, F2 not met, F3 met).
5. The Phase 7 author check (30 steered Hindi replies) is graded. **Done:** 29 of 30 agree.
6. No compute is running. Checked after every run: each pod was terminated, and its removal was confirmed by listing.

## Main finding

Both models show a large explicit-refusal gap between Hindi and English on the same requests. The causes differ:

- **Qwen3-8B:** Hindi harm is recognised at English strength, and the missing explicit refusals mostly become soft refusals. A push along an
  English-fitted explicit–soft direction raises Hindi explicit refusal, but it raises English too, and it did not pass confirmation on Bengali.
- **Llama-3.1-8B:** Hindi harm is recognised weakly (28% of the English projection), and the missing refusals mostly become compliance.

## Future work

Ordered by how directly each item follows from the results.

1. **Llama, beyond Phase 7.** Phase 7 tests a Hindi-set gate with pushes along the refusal direction and the explicit–soft
   direction. Left for later: a language-conditional gate, other layers, and sampled decoding.
2. **Llama: confirmation on fresh data.** The Phase 7 test reuses the Phase 6 test items, so a fresh Hindi set (or a second language)
   would be the confirmation step that Phase 4 was for Qwen.
3. **Qwen: neuron shift sweep (drafted as Phase 5b, not run).** This tests larger shifts (k ∈ {2, 3}) of the 100 Phase 5 neurons on
   development items, against random neurons, to see whether Hindi moves at all before damage. The draft is kept with the working notes.
4. **A fix that narrows the gap rather than raising every language.** Every Qwen push raised English as much as Hindi. A language-conditional
   gate, or a direction fitted on the Hindi–English difference, is the natural next design.
5. **Non-mechanistic baselines:** translate the request to English first, or add a system prompt in the user's language. These give
   reference points for any activation-level fix.
6. **Fine-tuning** (for example LoRA on Hindi refusals), as an upper bound on what training can do compared with steering.
7. **Breadth:** more model families and sizes, more languages (Bengali was used for confirmation only), sampled decoding as well as greedy.

**Data constraint for any of these:** the sealed split, all Bengali IndicSafe items and the Phase 6 Llama test set are used. A new
confirmation set, untouched by any run here, is needed before any tuned fix can be claimed.
