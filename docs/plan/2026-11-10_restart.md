# Plan v2: measurement and data first, then diagnosis, then repair

**Date:** 2026-11-10. This plan replaces the execution order of `2026-11-06_mechanistic_repair.md` from here on. The goal is unchanged: raise Hindi and
Bengali refusal of harmful requests on Qwen3-8B toward the model's own English behaviour, without raising refusal of harmless requests and without retraining
the model.

## Why restart

Steps 1 to 8 produced a measured gap and several failed interventions, but no confirmed repair on the primary model. Reviewing them shows problems in the
process rather than in any one method:

| Problem | Effect |
|---|---|
| Refusal grading is not validated against people in Hindi or Bengali (Hindi agreement with the reference 0.55) | Every effect size is uncertain |
| About half the manifest is machine-translated (71,395 of 141,009 rows) | Failures may reflect translation artefacts |
| Model comprehension of each prompt was never checked | Some "failures" may be misunderstanding, not unsafe compliance |
| Benchmark labels disagree with the model's English policy (58% English refusal on IndicGuard "harmful") | Label-based targets mix two gaps |
| Few failure cases for fitting (60 to 64 per language in Step 8 development) | Detectors and edits are fitted on very little signal |
| Interventions were chosen before the failure was localised | Layers and mechanisms were guesses |
| One model, no replication of the one pass (Llama, Step 5) | Results do not generalise |

## What is kept

- Code: manifest builder, prompt rendering, resumable generation, judge, bootstrap utilities.
- Model pins, approved datasets, and the sealed 165-request MultiJail confirm split, still unread and used once at the end.
- Steps 1 to 8 as an exploratory record. Their results are reported, but no v2 decision or test uses their items.

## What is reset

- **Splits.** v2 draws new fit, development and test sets from the manifest's held-out pool, excluding every item rendered in v1
  (`baseline_items`, `gated_items`, `gated2_items`) and every task linked to them.
- **Target.** The model's own decision on the matched English prompt (parity), not the benchmark label. Benchmark labels are kept as a secondary readout.
- **Order.** No intervention is designed until the measurement gate and the diagnosis have run.

## Phases and gates

| Phase | Pre-registration | Gate to continue |
|---|---|---|
| 0. Measurement | `2026-11-10_v2_measurement_and_data.md`, Part A | Judge agrees with human grades at kappa ≥ 0.7 in each language |
| 1. Data | Same file, Part B | At least 400 comprehended failure triples per language in the fit set |
| 2. Diagnosis | `2026-11-10_v2_neuron_diagnosis.md` | A neuron set whose patching causes refusal beyond random neurons |
| 3. Repair | `2026-11-10_closed_form_edit.md` with its v2 addendum | Pre-registered pass rule on the v2 test set |
| 4. Confirmation | Written after Phase 3 | Sealed split, and a second model |

If a gate fails, the phase reports why and the next phase does not start. A failed Phase 2 gate is itself a result: refusal is not carried by a sparse neuron
set at these settings, and the repair moves to directions or subspaces.

## Compute

Phase 0 needs no GPU beyond replies that already exist. Phases 1 and 2 need forward passes and short generations, of the order of a few GPU hours together.
Phase 3 needs generation and grading on the test set. Each phase stops the pod when its last job ends, and results are copied and checksummed before any stop.

## Addendum, 2026-11-11: Hindi first

- **Development language:** Hindi. Phases 0 to 3 fit, select and diagnose on Hindi only.
- **Bengali:** a held-out transfer language. No Bengali item enters any fit, selection or diagnosis step. The Phase 3 edit, fitted on Hindi, is
  tested once on the Bengali v2 test set before the sealed split. This tests whether a Hindi fix transfers to a related language it never saw. Bengali
  refusal is graded by model reference only, and is reported that way.
- **Romanised Hindi (Hinglish):** a supplementary Hindi test set, from a published prompt bank if one can be obtained, otherwise model-written
  conversions of v2 Hindi test prompts with a human naturalness check on 50. Deliberately misspelled keywords are a separate robustness test.
