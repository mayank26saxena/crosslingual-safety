# Phase 3 test: gated explicit-refusal steering, held-out test split (2026-11-14)

Pre-registration: `docs/prereg/2026-11-13_v2_phase3_gated_steering.md` (Procedure step 2, Outcomes and pass rule). The analysis script
(`scripts/v2/phase3_test_analysis.py`) was committed (3046993) before any test label existed. This step was run once.

**Setup.** The setting chosen on the development split (`2026-11-14_phase3_tuning.md`): α = 1.25 times e_dir[24] added at the layer-25 input,
gated on the layer-14 last-prompt-token score exceeding τ = 5.515 (50th percentile of English development harmful scores). 404 understood
harmful and 169 understood harmless test prompts, each in Hindi and English, and 300 Global-MMLU questions per language, generated unsteered
and gated in one run with identical batches (A40, pinned environment, `results/v2/phase3/test/env.txt`). 1,530 distinct replies graded blind by
claude-sonnet-5.5 subagents with all conditions shuffled (31 parts, every completed part self-reported `claude-sonnet-5-5`); 762 gated replies
identical to their unsteered reply took its label. No DECLINED labels and no pairs dropped.

**Grading incident.** The first grader for part 13 (50 rows) was stopped by the grading model's safety filter before writing any label. The part
was retried once with the identical prompt, before any test result was computed, and the retry completed. The decision to retry was made
before the analysis was run.

## Interpretation and limits

- **The intervention passes but does not close the cross-lingual gap.** The gate fires at the same rate on English and Hindi harmful prompts,
  so English explicit refusal rises almost as much as Hindi. The English minus Hindi gap in explicit refusal goes from 31.9 to 30.7 points, and
  in any refusal from 12.6 to 10.6 points. The pre-registered rule asked for a Hindi rise without English harm, which is met; it did not ask
  for the gap to shrink, and it does not materially.
- **The effect is a conversion of soft into explicit refusal**, with a smaller real shift from compliance: Hindi COMPLY falls 3.7 points and
  any refusal rises 3.5, as on the development split.
- **The general-ability and over-refusal checks are weak tests here.** The gate never opened on a Global-MMLU question and opened on 1 of 169
  harmless prompts per language, so those replies are (almost) identical by construction. They show the gate keeps steering off benign inputs;
  they do not show what steering does to a benign input when it is applied.
- **No effect on IndicSafe.** The gate opened on 2 of 67 IndicSafe prompts in either language, so the result rests on Aya red-teaming items.
- The test estimate (+17.1) is close to the development estimate (+21.4), smaller as expected for a setting chosen as the best of nine.
- Sealed MultiJail and Bengali have not been touched; they are Phase 4.
